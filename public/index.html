How to Play

Guess the five-letter word in six attempts or less.

Each guess must be a valid five-letter word.

Guess Feedback

Green: Correct letter and position.

Yellow: Correct letter, wrong position.

Gray: Letter is not in the word.

Multiplayer

Race against another player to guess the same five-letter word. The first player to guess correctly wins. Using all six attempts without guessing correctly results in an automatic loss!
